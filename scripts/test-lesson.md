# 测试教材：概率论基础

## 事件与样本空间

概率论是研究随机现象的数学分支。随机现象的结果在事前是不确定的。我们将所有可能结果的集合称为样本空间，记作 Ω。样本空间的每个元素称为样本点。

## 古典概型

当样本空间有限且每个样本点等可能时，事件 A 的概率定义为 P(A) = |A| / |Ω|，即有利样本点数除以总样本点数。

## 条件概率

在事件 B 已经发生的条件下，事件 A 发生的概率称为条件概率，记作 P(A|B) = P(A∩B) / P(B)。

## 贝叶斯公式

P(A|B) = P(B|A)P(A) / P(B)。这个公式描述了如何根据新的证据更新先验概率，是机器学习中很多算法的基础。

## 随机变量

随机变量是一个从样本空间到实数集的函数。离散随机变量和连续随机变量使用不同的数学工具描述。

## 期望与方差

期望 E[X] 是随机变量的加权平均值，方差 Var(X) = E[(X-μ)²] 描述随机变量偏离期望的程度。标准差是方差的平方根。

## 大数定律

当试验次数趋于无穷时，样本均值依概率收敛于期望值。这是统计推断的理论基础。

## 中心极限定理

独立同分布随机变量之和近似服从正态分布，无论原始分布是什么。这是置信区间和假设检验的理论基础。
